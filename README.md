## 🚀 Local Development

1. **Clone the repository with submodules:**
   ```bash
   git clone --recurse-submodules https://github.com/fhmio/fhmio.dev.git
   cd fhmio.dev
   ```

2. **Run local development server:**
   ```bash
   npm run dev
   # or directly:
   hugo server --minify -D -E -F
   ```

3. Open `http://localhost:1313` in your browser.
